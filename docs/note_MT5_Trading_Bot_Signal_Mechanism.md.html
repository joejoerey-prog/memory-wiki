# How the Trading Bot Reads Telegram Signals

The bot uses a Python library called Telethon, not a standard Telegram "Bot". This is the key to accessing a private channel. Telethon allows a script to connect to Telegram's network by acting as a real user account (your account).

### Step-by-Step Process

1. Credentials: You will provide an `api_id` and `api_hash` obtained from your account on [my.telegram.org](https://my.telegram.org). These are developer keys that authorize your script to connect to your account.

2. One-Time Login: The first time the script runs on the VPS, it will require a manual login. You will need to provide:
Your phone number.
A login code sent to your official Telegram app.
Your Two-Factor Authentication (2FA) password, if enabled.

3. Session File: Upon successful login, Telethon creates a `.session` file. This file contains the authorization key, allowing the script to reconnect automatically in the future without needing your credentials or a new code. This file is stored securely on your VPS.

4. Channel Monitoring: Since the script is authenticated as you, it can see all your chats, including the private ProTrader channel. We will configure the script to monitor this specific channel.

5. Real-Time Event Listening: The script will run continuously, listening for a "new message" event from the target channel.

6. Instant Parsing: The moment a message is posted, the script will grab its text content and immediately apply the parsing rules we defined to extract the trade parameters.

7. Execution: The parsed data is then sent to the MT5 component to place the trade on your PU Prime account.

This method allows the bot to operate reliably and instantly, just as if you were manually reading the signals and placing the trades yourself.

# Agents bridge rules

## Purpose
This folder is the shared bridge between Mac Hermes and VPS Hermes.

## Ownership
- Mac Hermes may write to ./mac/
- VPS Hermes may write to ./vps/
- Both agents may read ./shared/
- ./handoffs/ is for explicit requests passed from one agent to the other

## Safety
- Do not edit or summarise by modifying ../MEMORY.md or ../USER.md
- Do not move, rename, or delete existing top-level memory folders
- Do not store secrets, API keys, tokens, passwords, or credentials in this bridge

## Writing rules
- Prefer new dated markdown notes over overwriting existing files
- Keep notes short, factual, and scoped
- Promote only distilled facts, summaries, and handoff context into ./shared/
- Use ./handoffs/ for clear task transfer between agents

# MT5 Telegram Trading Bot Implementation Plan

For Hermes: Use subagent-driven-development skill to implement this plan task-by-task.

Goal: Create a trading bot running on a Linux VPS that receives gold trading signals from a private Telegram chat and executes them on PU Prime MT5.

Architecture: A Python Telethon client monitors the Telegram chat, parses the message, and sends the trade parameters via a local network socket. A native MQL5 script running inside MT5 on Wine acts as a socket client, receives the commands, and opens/modifies trades.

Tech Stack: Python, Telethon, Wine, MetaTrader 5, MQL5, Docker.

---

### Task 1: Setup VPS environment with Wine and MetaTrader 5

Objective: Install Wine and run MetaTrader 5 on the Linux VPS in a virtual frame buffer.

Files:
- Create: scripts/setup_env.sh
- Create: scripts/run_mt5.sh

Step 1: Install Wine, Xvfb, and winetricks on the Ubuntu droplet.
Step 2: Start a virtual frame buffer on display port 99.
Step 3: Download and install the PU Prime MT5 terminal inside the Wine prefix.
Step 4: Launch the terminal and log in with your PU Prime credentials.

Verification: Run a process check to verify terminal.exe runs under Wine.

---

### Task 2: Develop Python Telegram Listener

Objective: Create a Python client using Telethon to connect to your Telegram account and listen to the target channel.

Files:
- Create: src/telegram_listener.py
- Create: src/config.py
- Create: requirements.txt

Step 1: Write requirements.txt with telethon.
Step 2: Write config.py to load API ID, API hash, and target channel name from environment variables.
Step 3: Create telegram_listener.py using Telethon to log in and listen to the channel.
Step 4: Parse messages to extract order type, entry price, stop loss, and take profit stages.

Verification: Run python src/telegram_listener.py and send a test message to a test channel to verify extraction.

---

### Task 3: Develop Python Socket Server

Objective: Create a local TCP socket server in Python to forward signals to MT5.

Files:
- Create: src/socket_server.py
- Modify: src/telegram_listener.py

Step 1: Write socket_server.py to open a local TCP port and listen for connections.
Step 2: Update telegram_listener.py to send parsed trade data to the socket server.
Step 3: Handle disconnects and retries on both sides.

Verification: Run python src/socket_server.py and verify it accepts local connections.

---

### Task 4: Develop MQL5 Socket Client

Objective: Write an MQL5 script for MetaTrader 5 to connect to the local Python socket server.

Files:
- Create: src/mt5_socket_client.mq5

Step 1: Write mt5_socket_client.mq5 using native MQL5 socket functions.
Step 2: Connect to the local port on startup.
Step 3: Parse incoming JSON strings containing action, stop loss, and take profit.
Step 4: Execute orders using the Trade library.

Verification: Compile the script in MetaEditor and drag it onto a gold chart. Verify connection in the MT5 Experts log.

---

### Task 5: End to End Integration

Objective: Run all components together and test with a simulated Telegram signal.

Files:
- Create: scripts/run_bot.sh

Step 1: Start Xvfb and MetaTrader 5.
Step 2: Start the MQL5 script inside MetaTrader 5.
Step 3: Start the Python socket server and Telegram listener.
Step 4: Send a test signal in the monitored Telegram chat.

Verification: Verify the trade executes instantly on the MT5 gold chart with correct stop loss and take profit targets.

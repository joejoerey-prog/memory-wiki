✅ SHORTERY + CLEANVPN AUTOMATION (MacBook)

What it does:
Automatically turns CleanVPN ON when Safari or Brave opens, and OFF when they close.

Tools used:
• Shortery (Mac automation app)
• CleanVPN (VPN app with a working Shortcut to toggle VPN)

To Set Up:

▶ Connect VPN on App Launch
1. Open Shortery
2. Click + to add new automation
3. Event: App → When app launches
4. App: Safari (or Brave)
5. Action: Run Shortcut → Connect VPN

🛑 Disconnect VPN on App Quit (optional)
1. Event: App → When app quits
2. App: Safari or Brave
3. Action: Run Shortcut → Disconnect VPN

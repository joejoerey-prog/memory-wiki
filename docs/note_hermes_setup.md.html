# Hermes Obsidian Setup Prompt

This prompt was used to set up the Hermes agent with Obsidian integration.

---

Set up my Hermes agent so Obsidian is the persistent memory store on my MacBook Air. Use my local Obsidian vault as the source of truth, create a clean folder structure for memory and captures, and verify Hermes can read and write markdown notes there. Keep Littlebird as the activity capture source and wire its output into the same vault so Hermes can summarize it into long term memory. Before making changes, inspect the existing Hermes config and my Obsidian vault location. Then:

- create or confirm a vault path.
- configure Hermes to use that vault.
- create folders for memory, captures, and summaries.
- test read and write access with a sample note.
- report the exact files and settings changed.
- stop and ask for approval before any destructive change.
